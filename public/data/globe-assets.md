# Globe asset sources

`globe-destinations.geojson` contains China, India, Malaysia, and South Korea
extracted from Natural Earth's 1:50m Admin 0 Countries dataset. Properties were
reduced to a destination ID and country name; the source geometries are unchanged.

- Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson
- License: public domain — https://www.naturalearthdata.com/about/terms-of-use/

`../textures/earth/earth_clouds.jpg` is the unmodified 2K Earth Clouds texture by
Solar System Scope, based on NASA imagery.

- Source: https://www.solarsystemscope.com/textures/
- Download: https://www.solarsystemscope.com/textures/download/2k_earth_clouds.jpg
- License: Creative Commons Attribution 4.0 International — https://creativecommons.org/licenses/by/4.0/
- Visible credit is included in the site footer.

The globe's remaining Earth textures were already present in the project.
Cloud movement and sunlight are illustrative animations, not live weather or
real-time astronomical data.
